## Catalog Structure

### CSV Schema
```csv

```

### Field Definitions
- **path** - Relative path from `/mnt/d/silk/silklife/`
- **type** - File extension (`.webp`, `.png`, `.jpg`)
- **dimensions** - `WIDTHxHEIGHT` (e.g., `1024x1024`)
- **date_modified** - Last modification timestamp
- **model** - AI model used (upgraded: `gemini-3-pro-image-preview`, original: `gemini-2.5-flash`)
- **description** - Clean image description (f/11 wrapper removed)
- **upgraded** - `true` or `false`
